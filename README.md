# Ticket Management System

Ticket management system built with React, TypeScript, Vite, Tailwind CSS, React Router, and a Supabase PostgreSQL/Auth backend.

## Project structure

- `frontend/` — React application
- `backend/supabase/` — Supabase schema, migrations, triggers, RLS policies, and seed data
- `docs/` — project documentation

## Frontend development

```bash
cd frontend
pnpm dev
```

Build and type-check from the `frontend` directory:

```bash
pnpm exec tsc --noEmit
pnpm build
```
